# نظام المبيعات وقياس الأداء - معهد البيان

## الرفع على Hostinger

1. من hPanel افتح **File Manager** وادخل على `public_html` (أو فولدر فرعي مثل `public_html/sales`).
2. ارفع الملفين: `index.html` و `api.php`.
3. افتح الرابط (مثلاً `https://your-domain.com/sales/`). أول مرة الملف `api.php` بينشئ تلقائياً فولدر `data` اللي فيه البيانات، ومقفول عن الوصول المباشر.

بعد كده أي بيانات تسجلها بتتحفظ على السيرفر وتظهر نفسها على الكمبيوتر والموبايل.

### ملاحظات
- لو كان عندك بيانات مسجلة قبل كده على متصفح معين، افتح الرابط الجديد **من نفس المتصفح ده الأول**، وهو هيرفعها للسيرفر تلقائياً (لو كانت على نفس الدومين). أو استخدم "النسخ الاحتياطي والاستعادة": نزّل نسخة من الرابط القديم واستعدها في الرابط الجديد.
- **كلمة مرور (اختياري ومُستحسن):** افتح `api.php` وغيّر السطر `$PASSWORD = '';` إلى كلمة مرور، مثلاً `$PASSWORD = 'Albayan@2026';`. كل جهاز هيطلبها مرة واحدة بس.
- السيرفر بيحتفظ بنسخة سابقة واحدة في `data/db.prev.json` كاحتياط.
- لازم الملفات تكون على Hostinger (أو أي استضافة PHP). على GitHub Pages الصفحة هتشتغل بس البيانات هتفضل على الجهاز فقط.
